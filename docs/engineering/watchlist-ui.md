# 清單、卡片與詳情互動

修改清單排序、提醒、卡片、搜尋或 DetailModal 互動時查閱。共用配色、載入、焦點與控制項見 [共用視覺樣式](visual-style.md)。觀看紀錄與分享規則見 [資料一致性](accounts-and-data.md#觀看紀錄與進度)；變更已播出計算或補查時再讀 [TMDB 與集數資料](tmdb.md#集數計算與補查)。

## 清單狀態與提醒

- `已看 X / Y` 的分母統一使用「已播出集數」，不得回退「已知總集數」。未載入季度、查詢失敗或資料數量不一致，且沒有可用上次分母時，保留已看數並標示「已播出待確認」，不畫猜測的進度條。等於目前分母且沒有漏集警告時用綠色；未看完用淡藍色，漏集警告優先用黃色。
- 「已看完目前已播出集數」在首頁 badge 也視為 `completed`，不能和清單文字打架。
- TV / Anime 若有 `有新集數播出` 提醒，應排在 `正在觀看` 清單最前面。
- 新集數提醒的「今天／幾天前」以 `next_episode_air_date` 的實際播出日計算，不以系統何時發現更新的 `alert_started_at` 計算；舊資料缺少播出日時才退回發現時間。首播提醒則以作品 `release_date` 計算。
- TV / Anime 沿用既有集數掃描入口與共用快取，在清單標題旁顯示精簡提示：掃描進行中顯示「正在確認更新…」、有未讀的新集數 / 首播提醒時顯示發現更新的作品數，掃描成功且沒有更新時顯示「已完成更新檢查」。提示本身不得發送查詢。資料新鮮度由活動期間的六小時檢查週期負責，恢復真正操作時檢查；不得略過快取或新增高頻網路輪詢，也不要混入「已置頂」等實作細節。
- 清單內若同一天有多筆已看紀錄，排序需用最新那筆觀看紀錄的建立時間做 tie-break；後新增的排前面。
- TV / Anime 若尚未播出且使用者還沒有任何觀看紀錄，清單卡片文字顯示「尚未播出」，不要寫成「尚未觀看任何集數」。
- `watchlist_tv_states` 的提醒欄位屬於可持久化的 state / cache，不只是前端記憶體狀態。
- TV / Anime 作品完全移出清單且沒有其他分區項目時，需一併清除該作品的 `watchlist_tv_states`，避免重新加入後沿用舊提醒。
- TV / Anime 若加入清單時尚未播出，首集播出後顯示「已開始播出」並置頂；新集數與首播提醒都在集數清單成功載入後視為已讀並清除，未開啟前持續顯示。
- 新集數與首播提醒只出現在清單，因此只有使用者從清單提醒入口開啟作品，且集數清單成功載入後才標記已讀；從首頁、搜尋、Header 或其他詳情入口查看集數時，不清除清單提醒。
- `season lookup` 失敗沿用既有最多一次重試；TMDB 429／共用冷卻期間不得立即重送，遵守 Retry-After。仍失敗時保留上一輪狀態，顯示「暫時無法確認最新集數」。
- 「即將播出」分頁一部作品可能同時來自兩季：目前正在播、還有未播出集數的那一季，加上下一季已經有集數資料但還沒開播的情況（`src/lib/upcomingEpisodeSeasons.ts` 的 `getUpcomingCandidateSeasonNumbers`）。忽略 TMDB 續訂後先建的空殼季（`episode_count` 是 `null`/`0`），且最多只查最新兩個已知季；這是限制「即將播出」查詢成本的策略，不能據此認定較早季已全部播畢，更不能拿未載入季估算已播出總數。

## 卡片與清單排版

- 卡片採 A「留白精修」樣式：平面深灰背景、13px 圓角、16px 內距與卡片間距；海報 80 × 116px，片名桌面 16px、小螢幕 15px。不得增加陰影或漸層層次；滑入僅輕微位移且尊重減少動態偏好。圖片／骨架佔位不閃爍，載入中另外搭配共用旋轉圈。集數進度使用共用播出日期與一致的觀看計數；允許在原掃描完成後補查缺少的季度，未知分母時顯示待確認並隱藏進度條。不得增加高頻輪詢。
- 卡片集數狀態與分母文字不保留閒置旋轉圈的前方空位；更新中才在文字後方顯示小圈，保留既有全文提示及換行方式。
- 卡片採精簡排版：有效集數進度與下一集／集名或已追完狀態並列保留，計數與對應的集數分母標籤同列、3px 細條置底；漏集、資料不完整、載入及上映倒數等重要狀態維持原文，不因精簡而隱藏。不得固定內容高度造成文字裁切。
- 電影、影集與動畫沿用原本的分類分頁與列高，選中分頁使用深灰底與 7px 圓角，未選中分頁弱化邊框；維持鍵盤焦點提示與選中狀態語意。
- 同步與更新檢查進行中使用低調灰字及共用旋轉圈，結束後使用靜態提示；待確認用淡黃、失敗用錯誤紅、明確成功用淡綠並搭配文字，提示不新增查詢。
- 清單標題列在 sm（640px）以上維持單行：左側名稱／筆數／同步與更新資訊，右側清單內找片；標題與提示可截斷、輸入框隨空間縮短，清除鈕置於輸入框內避免擠壓。小螢幕上下兩行，搜尋靠右，不再顯示 TMDB 搜尋範圍說明；不新增請求。
- 已看電影卡片採緊湊排版，兩行片名加上映日、好友列及觀看資訊盡量維持在既有海報高度內；好友列最多 4 個小頭像，其餘用 +人數表示，完整姓名保留在提示與輔助閱讀名稱。觀看資訊單行截斷並保留完整提示，不裁切固定高度、不新增資料查詢。
- 影集／動畫卡片有有效進度時仍須顯示既有 episodeStatus（下一集編號與集名、已看完目前已播出等）；不可為進度條隱藏這些資訊。影集／動畫不顯示上映日，提醒放於片名下方，狀態單行截斷並提供全文提示；保留「已看完」與「已看完目前已播出集數」兩種既有判斷。電影的上映日、「今天上映」與「N天後」倒數不受影響，不新增查詢。
- 卡片進度配色：未看完用低飽和淡藍、已達目前已播出分母用綠色；漏集／集數資料不完整優先用黃色數字及進度條。警告不應單獨阻擋有效進度，沒有可靠分母且沒有上次已確認值時隱藏進度條。同步／更新確認中可保留有期限的上次已播出分母，但必須標示「已播出 · 待更新」；已看數仍使用目前帳號的已同步計數，不能把舊資料當最新。
- 清單內找片只篩選目前已載入的片名，涵蓋分組與即將播出集數；搜尋字詞不可加入資料抓取／同步 effect 相依，不可為搜尋補抓 TMDB。同步提示可縮短但不可把未驗證的本機快取標為已同步。

## 頂部導覽

- 頂部主列維持 64px 高，左側「首頁／電影／影集／動畫／行事曆」採 A 細底線樣式：選中頁面用較亮文字與 2px 底線，其餘低亮度呈現；連結維持原路由、關閉搜尋及不預抓頁面的行為。
- 小於 640px 時沿用目前頁面選單，按鈕採 40px 高、7px 圓角並加下拉箭頭；小於 820px 時展開搜尋，沿用隱藏導覽與頭像的既有排列。
- 右側搜尋、頭像與好友提醒保留原版樣式、尺寸及操作，不套用 A 範例的搜尋文字框或頭像配色。導覽樣式不新增資料請求。

## 首頁推薦

- 推薦資料與清單／觀看狀態讀取共用標題同排的一個載入提示，完成後不留空白列；窄畫面只顯示具可讀名稱的旋轉圈；推薦載入中優先顯示推薦訊息，完成後若私人狀態仍在讀取才切換文字。不得同時顯示兩個相鄰旋轉圈，保留各自錯誤／重試及卡片海報、收藏操作的獨立提示；不為合併顯示調整查詢或等待順序。
- 首頁分類與推薦卡片沿用清單的平面風格：卡片 13px 圓角、10px 內距，卡間距桌面 12px／手機 10px；卡寬依畫面調整，保留 2:3 海報比例、兩行片名及原本圖片來源。首頁透過 `MediaCard` 的 `presentation="home"` 使用新樣式，搜尋結果採同系列平面卡片，使用 `presentation="search"`，不掛入首頁輪播的操作屬性。
- 推薦列的 Grid 欄寬必須限制在容器內（單欄 `minmax(0, 1fr)`，區塊可縮至零寬），不得讓循環卡片的內容寬度撐大頁面。初始留白遮罩與卡片偏移共用實際容器寬度的計算結果。驗證須包含真實首頁多排推薦的 Grid 外框，不能只測獨立輪播元件。
- 首頁輪播採 A 均勻半透明箭頭，覆蓋邊緣卡片的完整高度，包含片名、狀態及星號區；初始左側小幅留白且隱藏左箭頭，第一次瀏覽以動畫調整卡寬，之後左右固定露出同樣大小的半張卡片。箭頭寬度由目前排版的半張卡寬決定，滾動時不追隨逐張卡片的裁切寬度，也不因間隙經過而閃隱；移動中的卡片仍攔截點擊。完整可見的卡片才能開詳情或切換清單；部分及不可見卡片不能由滑鼠或鍵盤誤操作。
- 箭頭依可見卡片數整組翻頁，正常手機至少 2 張，必要時調整翻頁張數，確保只按箭頭也能完整瀏覽每部作品；拖曳仍可逐張瀏覽，相同片單可雙向連續循環。資料只有一筆時顯示完整卡片，不提供無意義的循環。循環副本只在呈現層有界建立，共用原本觀看／清單狀態，不擴增推薦或私人狀態查詢；副本圖片不加入優先載入。尊重減少動態偏好，閒置或開啟全站搜尋隱藏首頁時停止動畫追蹤，回到首頁時恢復位置；切換分類或換資料時清理事件及動畫。
- 首頁觀看狀態放在海報下方，與年份及清單星號分開；已看完用綠色、未看完用淡藍色。沿用既有觀看狀態與清單資料，保留星號的獨立按鈕、更新中／待確認防護和輔助閱讀名稱，不新增查詢。
- 首頁文字採 A 對齊方案：主標、區塊捷徑、更新時間、各排標題與狀態提示對齊首卡的初始起點（輪播實寬大於 640px 時為 40px，較小時為 36px），翻頁後文字位置固定。保留原分類列、Grid 與輪播寬度，只調整文字區塊內距；響應條件使用實際內容寬度，避免捲軸造成斷點落差。頁面主標與各排標題維持既有大小層級，更新時間精簡顯示並以提示保留完整時間；時間來源與時區語意不因排版而改變。
- 區塊捷徑只使用目前分類已載入的推薦清單，透過頁內連結跳到對應區塊；載入或錯誤時不提供無效捷徑。目標位置須預留固定導覽列空間，不改推薦載入、快取或排序。

## 全站搜尋

- 搜尋保留原頂部輸入框與頭像；中文輸入法選字完成後才開始 400ms 延遲查詢。換字詞、關閉或離開頁面會取消舊請求，不能讓舊結果混入新搜尋。
- 初次只載入第一頁，後續由「載入更多」一次取一頁，不預抓或無限自動載入；跨頁依作品類型與 id 去重。下一頁失敗保留既有結果，重試仍取同頁；只有人物的頁面也可繼續手動取下一頁，不把過濾後的零筆當成沒有後續。
- 「搜尋結果」、搜尋字詞與「目前載入 X 部」維持同一行；窄螢幕優先縮短搜尋字詞並以提示保留全文，標題與筆數不換行；電影／影集／動畫只篩選已載入作品，切分類不觸發公開或私人查詢，換字詞重設分類。卡片沿用首頁平面樣式、狀態置於海報下方與獨立星號，網格連續自適應；初次載入使用靜態佔位搭配旋轉圈與載入文字。
- 前端公開分頁快取維持固定 10 分鐘、最多 50 頁；只含公開作品資料，後續分頁不得延長較早頁的期限。關閉再開啟可保留尚未過期的已載入頁，過期後重新取得第一頁；伺服器搜尋快取維持 30 分鐘。
- 新分頁只補查新出現作品的清單／觀看狀態，切分類不重查；重開、手動重試與既有即時更新仍依原流程更新，請求有界分批，保留未知狀態、錯誤及操作防競態。禁止把後頁成功當成前頁私人狀態已恢復。

## 詳情互動

- 詳情彈窗採 B 霧面外框，維持原深黑色調；星號與關閉按鈕保留圓框。桌面最高 600px，受視窗可用高度限制，詳細資料／觀看紀錄維持同高；小視窗保留全螢幕布局。
- 詳細資料採 B 緊湊摘要：海報等比例且在內容區垂直置中，右側文字區與海報等高、上下對齊；片名與基本資料固定靠上，僅簡介超出剩餘空間時捲動。系列電影入口保留，展開後使用原閱讀區捲動，不增加查詢。
- 觀看紀錄採 C 時間軸，每筆紀錄／每集獨立一列並用淡分隔線區分；觀看日期與好友維持同列，過長可在該列水平捲動。OWNER 沿用黃色頭像邊框與姓名，不新增建立者文字；右側操作圖示與「N天後播出／尚未播出」提示垂直置中，影集／動畫保留原日曆 SVG。季數選單靠左且不重複顯示選單內資訊。
- 觀看紀錄改版保留首次定位未看集數、編輯／儲存後定位該集、手動換季與背景同步不搶走捲動位置的原流程；遠距離定位直接跳轉，近距離沿用平滑捲動。

- 電影與影集／動畫同步衝突使用一致文案，指出哪位好友有衝突，提供取消勾選或請好友確認原紀錄兩種處理方向。維持直接同步、整筆衝突時不寫入觀看紀錄或分享；不增加逐筆同意。衝突資訊範圍見 [好友分享規則](accounts-and-data.md#交易鎖與分享)。
- 詳情錯誤提示停留六秒，讓使用者有時間閱讀處理方式；成功提示沿用原本短暫顯示。不為提示增加查詢。

- 電影、影集與動畫的日期／好友編輯採 C 側邊面板：桌面右側 448px、小視窗滿寬，標題、日期及底部確認列固定；好友維持兩欄四排，超過 8 位才在好友清單內捲動，正常手機不捲動整塊編輯區。極矮視窗或錯誤訊息較長時優先縮短好友可視區，保留日期與確認操作；過長的錯誤訊息另在有高度上限、可用鍵盤捲動的提示區內完整閱讀，重試入口保留，不得將日期或底部按鈕推出面板。好友名稱截斷時保留完整提示，不論好友人數皆顯示本機搜尋框；搜尋、選擇與收起不新增查詢。
- 日期欄位維持原生選擇器，寬 200px、高 40px並加大日曆點擊區；提供今天、昨天與已載入的自己近期紀錄日期捷徑，不取好友的觀看日期作捷徑。保留 date-only、不可晚於今天及原本上映／播出與 OWNER 限制。
- 編輯面板不放重複的關閉叉號，保留底部取消、點暗色外側收起及 Escape；同一筆尚未確認的日期／好友只在目前詳情暫存，重開可繼續。換紀錄／集數／季、作品、帳號、關閉詳情或成功儲存後清除草稿；未確認不寫入，送出中不可收起或關閉。原詳情外層關閉按鈕保留。
- 首次進入沒有觀看紀錄的已上映電影時，沿用直接展開新增編輯的流程；收起後提供新增入口，背景刷新不得反覆展開。編輯期間延後自動刷新但保留共用連線；沒有更新訊號時，收起直接回到原清單，不重新查詢。若有待更新訊號則合併在背景補查，同帳號／作品／季度已載入的集數列保持顯示與捲動位置。保留電影與集數原本的提交、衝突處理及自動捲動；切換作品後忽略舊儲存回覆與衝突提示。
- 自動刷新詳情彈窗內容時，要保留 history 區塊原本的捲動位置；只限自動刷新，不影響開啟時預設捲動，也不要動畫。
- 電影日期選擇器與 TV / Anime 一樣，使用者正在開啟日期選擇器時要暫停自動刷新，避免選擇器被刷新關掉。

## 讀取失敗與操作保護

- 清單首次讀取前維持載入狀態；空快取不能證明目前沒有作品，須等本輪清單讀取及既有的有界空回應重試完成後，確認為有效空陣列才顯示「目前尚未加入任何內容」。確認前不先顯示零筆；非空快取仍先顯示，讀取失敗或回覆互相矛盾時保留資料並顯示重試，不將矛盾的空回應覆寫快取，也不增加輪詢或重試上限。
- 首頁、搜尋和詳情的私人狀態要區分「未知」與已確認的空白／未加入。讀取失敗時保留同帳號、同作品的成功資料，顯示錯誤並提供手動重試；切帳或換作品不得沿用其他範圍的狀態。未知的清單操作暫停，不能把讀取失敗當成可以新增。
- 首頁與搜尋目前範圍的作品尚未完成本輪清單查詢時，顯示載入提示；包含首次結果出現及追加分頁、請求尚未開始的短暫階段。只有本輪查詢已完成仍有未知狀態，才顯示「清單狀態待確認」與重試；實際讀取錯誤照常顯示。此判斷沿用既有請求與完成狀態，不為提示增查，也不能讓後頁完成掩蓋前頁仍在等待。
- 清單增刪與觀看紀錄提交以作品為單位防止重複送出；影集／動畫分類共用同一作品鎖。背景讀取和寫入分開管理，較舊的查詢結果不得覆蓋較新的操作，也不得提前解除操作鎖。詳情系列作品清單同樣適用。
- 公開推薦、搜尋和作品詳情讀取失敗提供手動重試，沿用 TMDB 冷卻規則；不增加自動重試迴圈或定時查詢。
- 搜尋的取消與 Escape 關閉搜尋視窗，但保留字詞與結果供再次開啟。若詳情或確認視窗正在處理 Escape，不應連帶關閉背景搜尋。

## 鍵盤與視窗大小

- 推薦卡片的詳情入口使用獨立原生按鈕，與清單星號分開，支援 Tab、Enter 與 Space。
- 詳情及其確認視窗使用 dialog 語意，開啟後將焦點留在最上層視窗；關閉後回到原操作入口。Escape 優先處理最上層視窗或編輯狀態，提交中與輸入法組字時不得誤關閉。
- 視窗寬度小於 820px 或高度小於 600px 時，詳情採用全視窗、單欄及可捲動內容；不再以尺寸提示阻擋使用。關閉列保留可見，確認視窗限制高度並可捲動。載入使用共用旋轉圈搭配文字；佔位不閃爍。
