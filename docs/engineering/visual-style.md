# 共用視覺樣式

修改配色、按鈕、載入、焦點、文字層級、浮層或捲軸時查閱。共用 CSS 位於 `desktop/watch-theme.css`，網站由 `src/app/globals.css` 匯入並對應 Tailwind 色名；Electron 啟動頁與外殼直接引用同一檔案，隨既有 `desktop/**/*` 一起打包。

## 顏色依用途區分

| 用途 | 色碼 | 使用方式 |
| --- | --- | --- |
| 未完成的觀看進度、鍵盤焦點 | `#a9c8df` | 進度文字／細條；2px 焦點框 |
| 已完成、明確成功 | `#a5d3b8` | 不把尚在讀取或待確認標成成功 |
| 待確認、漏集、資料不完整、需注意 | `#e4c17a` | 搭配明確文字，不只靠顏色 |
| 操作或讀取失敗 | `#e57373` | 錯誤狀態決定樣式，不搜尋訊息是否包含「失敗」 |
| 已收藏 | `#fff176` | 星號共用；未收藏維持中性 |
| OWNER 身分 | `#d9bd70` | 姓名及頭像邊框共用，與收藏／警告分開 |

- 月曆電影／影集／動畫的分類色保留，不能誤改成成功／失敗狀態色。桌面視窗關閉按鈕保留作業系統慣用的紅色滑入回饋。
- 背景、內容面板、輸入框、浮層各有共用色階，保留用途及層級差異。同類浮層使用 `watch-popover`，同類選中項使用 `watch-selected`；不把整站刷成相同灰色。
- 文字固定三級：主要 `#e6e6e6`、次要 `#bfc1c8`、輔助 `#868b95`。彩色狀態及反白按鈕文字另外按用途使用。

## 控制項與回饋

- 一般操作採 `watch-button`，標準最小高 36px／圓角 8px、小型最小高 32px／圓角 6px；主要、危險、低強調操作以修飾類別區分。圓形星號／關閉、視窗控制、分頁、日期／好友選項不強制改成一般按鈕。
- 輸入框可使用 `watch-input`，既有原生日期選擇器維持 200 × 40px。Header 搜尋框與頭像保留既有尺寸／外形。
- 所有可操作控制項有 2px 淡藍焦點提示。複合搜尋框畫在外層；季數選單、輪播邊緣或桌面視窗邊緣等會裁切的位置保留向內畫框，不為統一 offset 而裁掉焦點提示。
- 同類停用控制項採 0.5 不透明度與一般游標；停用時不能出現有效操作的滑入背景、位移或亮色。使用原生 `disabled` 保護提交中／不可操作的按鈕，不能只降低透明度。
- 網站載入中使用 `watch-spinner` 旋轉圈搭配文字或可讀名稱；桌面啟動頁依使用者偏好保留橫向載入條，詳見 [桌面版](desktop.md#執行環境與更新閘門)。待機／成功後不繼續旋轉。尊重減少動態偏好時停止旋轉但保留載入說明。圖片與搜尋骨架不閃爍，可同時顯示載入圈。
- 背景載入圈與既有標題／筆數／工具列同排，不另留空白狀態行；完成後移除提示。窄畫面可只顯示旋轉圈，保留可讀名稱及滑鼠提示，避免長訊息擠成第二行；標題與控制項不能被遮住。按鈕沿用既有尺寸並容納忙碌圖示及文字，不因載入而改變寬度。首次資料呈現及真實錯誤可自然改變版面，錯誤文字與重試仍須完整可讀。
- 「正在載入」、「成功載入且無資料」、「讀取失敗」是不同狀態。失敗保留同帳號、同範圍的上次成功資料與重試入口，不顯示誤導的空清單文字；切帳號不得帶入舊資料。
- 同類內容捲軸共用 thin／8px、`#555761` 滑塊及淡色軌道；保留原本各區域捲動、置中、定位和焦點範圍。

## 不影響資料的界線

以上視覺回饋使用既有載入、成功、錯誤與提交狀態，不因動畫或顏色新增 API、資料庫欄位、輪詢或快取刷新。卡片幾何、輪播完整可見判定、月曆跨日接合、詳情自動捲動與分享權限維持原規則。
